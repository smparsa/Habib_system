# راهنمای زمان‌بندی پشتیبان خودکار با Task Scheduler ویندوز

این راهنما نحوهٔ ساخت یک «وظیفهٔ زمان‌بندی‌شده» در ویندوز را توضیح می‌دهد تا نسخهٔ
پشتیبان دیتابیس **حتی وقتی سرور برنامه خاموش است** به‌صورت خودکار گرفته شود.

> نکته: اگر سرور برنامه روشن است، پشتیبان خودکار توسط خود برنامه (رشتهٔ پس‌زمینه)
> و طبق «بازهٔ زمانی» تنظیم‌شده در **پنل مدیریت ← پشتیبان‌گیری و بازیابی دیتابیس**
> انجام می‌شود. Task Scheduler برای مواقعی است که سرور خاموش است یا می‌خواهید
> یک نسخهٔ تضمینی با برنامهٔ دقیق‌تر داشته باشید.

---

## ۱) پیش‌نیازها

- مسیر پروژه: `C:\Habib_system`
- مفسر پایتون پروژه (venv): `C:\Habib_system\venv\Scripts\python.exe`
- فایل مدیریت جنگو: `C:\Habib_system\manage.py`
- دستور پشتیبان: `python manage.py db_backup`

قبل از هر چیز، یک بار دستی تست کنید که دستور کار می‌کند:

```bat
cd /d C:\Habib_system
venv\Scripts\python.exe manage.py db_backup --show
```

اگر خروجی، وضعیت تنظیمات و آخرین نسخه را نشان داد، همه‌چیز آماده است.

---

## ۲) ساخت وظیفه با رابط گرافیکی Task Scheduler

1. کلید **Win** را بزنید و `Task Scheduler` را جستجو و باز کنید
   (یا `taskschd.msc` را در Run اجرا کنید).
2. از منوی راست (Actions) روی **Create Basic Task…** کلیک کنید.
3. **Name**: یک نام بگذارید، مثلاً `Habib DB Auto Backup`.
   می‌توانید توضیحی هم بنویسید. **Next**.
4. **Trigger (زمان اجرا)**: «روزانه» (Daily) را انتخاب کنید و ساعت دلخواه را
   تعیین کنید (مثلاً هر روز ساعت ۰۳:۰۰ که ترافیک دیتابیس کم است). **Next**.
5. **Action**: «اجرای برنامه» (Start a program) را انتخاب کنید. **Next**.
6. در صفحهٔ «Start a Program» این‌ها را دقیقاً وارد کنید:

   | فیلد | مقدار |
   |---|---|
   | Program/script | `C:\Habib_system\venv\Scripts\python.exe` |
   | Arguments (استدلال‌ها) | `C:\Habib_system\manage.py db_backup --auto` |
   | Start in (شروع از) | `C:\Habib_system` |

   ⚠️ دقت کنید فیلد «شروع از» (Start in) خالی نباشد؛ وگرنه مسیرهای نسبی درست
   کار نمی‌کنند.

7. **Finish** را بزنید. وظیفه ساخته شد.

برای تست فوری: روی وظیفه راست‌کلیک کنید و **Run** را بزنید، سپس در پنل مدیریت
(بخش پشتیبان‌گیری) یا با دستور `--show` مطمئن شوید نسخهٔ جدید ثبت شده است.

---

## ۳) ساخت وظیفه با خط فرمان (روش جایگزین)

اگر ترجیح می‌دهید از خط فرمان استفاده کنید، یک بار PowerShell یا cmd را **به‌عنوان
مدیر** باز کنید و این دستور را بزنید (هر روز ساعت ۳ بامداد):

```bat
schtasks /Create /SC DAILY /ST 03:00 /TN "Habib DB Auto Backup" ^
  /TR "\"C:\Habib_system\venv\Scripts\python.exe\" \"C:\Habib_system\manage.py\" db_backup --auto" ^
  /RL LIMITED
```

توضیح پارامترها:
- `/SC DAILY` — تکرار روزانه
- `/ST 03:00` — ساعت اجرا
- `/TN "..."` — نام وظیفه
- `/TR "..."` — دستور اجرایی (پایتون + manage.py + آرگومان‌ها)

تست و اجرای دستی:

```bat
schtasks /Run /TN "Habib DB Auto Backup"
schtasks /Query /TN "Habib DB Auto Backup"
schtasks /Delete /TN "Habib DB Auto Backup" /F
```

## ۴) حالت‌های مختلف اجرا (آرگومان‌ها)

| آرگومان | کاربرد |
|---|---|
| `--auto` | نسخهٔ **خودکار** ثبت می‌کند (در فهرست پنل با برچسب «خودکار» و مشمول «تعداد نگه‌داری» است). **مناسب Task Scheduler.** |
| `--due` | فقط **اگر زمانِ نسخهٔ بعدی رسیده باشد** نسخه می‌گیرد (همان منطق رشتهٔ پس‌زمینهٔ برنامه). با این گزینه، Task Scheduler و رشتهٔ پس‌زمینه با هم تداخل ندارند. |
| (بدون آرگومان) | نسخهٔ **دستی** ثبت می‌کند (در فهرست با برچسب «دستی»؛ هرگز خودکار حذف نمی‌شود). |
| `--title "..."` | نام/برچسب دلخواه برای نسخهٔ دستی (مثلاً «پیش از به‌روزرسانی»). |
| `--note "..."` | توضیح دلخواه برای نسخهٔ دستی. |
| `--show` | نمایش وضعیت تنظیمات و آخرین نسخه — برای بررسی سلامت. |

پیشنهاد: در Task Scheduler از ترکیب `--auto` استفاده کنید تا نسخه‌ها مشمول
«تعداد نسخهٔ نگه‌داری‌شده» شوند و پوشهٔ پشتیبان بی‌نهایت بزرگ نشود.

---

## ۵) نکات مهم

- **تداخل با رشتهٔ پس‌زمینه:** اگر سرور برنامه روشن است و خودش پشتیبان خودکار
  می‌گیرد، نیازی به Task Scheduler نیست (یا از `--due` استفاده کنید تا نسخهٔ تکراری
  ساخته نشود). معمولاً بهترین حالت این است که Task Scheduler را برای ساعتی تنظیم
  کنید که سرور خاموش است.
- **فایل‌های لاگ:** اگر می‌خواهید خروجی/خطای دستور ذخیره شود، در بخش «Start a
  Program» گزینهٔ «Add arguments (optional)» را برای مسیر یک فایل `.log` پر کنید
  یا از Task Scheduler گزینهٔ «Open the properties dialog» را علامت بزنید و در
  تب Settings، «Run task as soon as possible after a scheduled start is missed»
  را فعال کنید.
- **حق دسترسی:** پیش‌فرض وظیفه با حساب کاربر فعلی اجرا می‌شود؛ اگر رمز حساب را
  تغییر دادید باید وظیفه را به‌روز کنید. برای اجرا بدون نیاز به ورود، در خواص
  وظیفه «Run whether user is logged on or not» را انتخاب کنید.
- **پشتیبان خارج از محل (کپی ابری):** در پنل مدیریت، فیلد «کپی خودکار به پوشهٔ
  درایو/فضای ابری» را با مسیر یک پوشهٔ همگام‌سازی‌شده (Google Drive، OneDrive یا
  درایو شبکه) پر کنید تا پس از هر پشتیبان موفق یک کپی هم به آنجا برود.
- **بازیابی:** از پنل مدیریت ← پشتیبان‌گیری و بازیابی، روی هر نسخه دکمهٔ «بازیابی»
  (با تأیید تایپ نام فایل) موجود است؛ یا فایل `.sql` را با `mysql` به‌صورت دستی
  بارگذاری کنید.

## ۶) بررسی سلامت

هر وقت خواستید مطمئن شوید پشتیبان‌ها مرتب گرفته می‌شوند:

```bat
cd /d C:\Habib_system
venv\Scripts\python.exe manage.py db_backup --show
```

و در **داشبورد پنل مدیریت** کارت «آخرین پشتیبان موفق» را ببینید؛ اگر بیش از تعداد
روزِ تعیین‌شده در تنظیمات («هشدار پس از چند روز بدون پشتیبان موفق») گذشته باشد،
کارت و صفحهٔ پشتیبان‌گیری هشدار قرمز نشان می‌دهند.
